Noise-wave calibration
======================
_The code and methods for doing noise-wave calibration_

Last updated: 2026-06-08

We currently use the noise wave calibration method of Kirkham et al.

The observing sequence is usually as follows:
1. Antenna (x sec)
2. TBC

We use laboratory VNA measurements to fix the reflection parameters. The measurements fir each component are kept in the rhino-sparams repo.
